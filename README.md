# Nix DevShell Tutorial

This is a short tutorial (or rather showcase) of one way of creating reproducible development environments with Nix. It shows how to create a development environment that compiles a [C program](https://github.com/cbeckerhd/NixDevShellTutorial_CProjectWithDependencies) from a Github repository and makes the binary available.

```
nix develop .nix
swap
```
